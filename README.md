# survival

## Aviso 

Esse é um projeto de estudo com o objetivo de desenvolver o meu conhecimento na unidade, com foco no 3D. 
A ideia foi fazer um protótipo com várias mecânicas de um jogo de sobrevivência, como inventário, criação de itens, coleta de recursos, etc...

Todos os Assets desse jogo foram adquiridos de forma gratuita no site da Unity <a href="https://assetstore.unity.com/" target="_blank">AssetStore</a>.

Download do jogo: <a href="https://igorsantos.itch.io/survival" target="_blank">itch.io</a>
